本轮实际改动
1. 新增小型 Python 标准库适配器。默认保持逐行 URI，不自动猜测；Base64 只展开一次，不抓取订阅网址，不筛掉坏行，不扩大协议支持。
2. 支持标准或 URL-safe 字母表，但同份输入不能混用；支持规范填充或完全省略填充、开头 UTF-8 BOM、ASCII 空格/制表/回车/换行。错误字符、错误填充、非规范尾位和空 Base64 整份拒绝，公开错误仅为固定码。
3. 包装文件与解码正文均设 512KiB 上限，先检查原始容量再移除折行空白。由于包装也受限，有效 Base64 正文最多约 384KiB，不能承诺 512KiB 正文容量。
4. 解码后无效 UTF-8、错误 UUID、重复参数和不支持协议继续逐条留账；重复配置仍按原规则归组，匿名报告结构保持 v1。
5. 界面增加明确的格式下拉选择，处理线程使用开始时选定的格式；处理期间关闭格式切换和复制，失败后清空旧摘要。离线包白名单和自检包含新增模块，CI 已加入新的入口测试及 Windows GUI 测试。
