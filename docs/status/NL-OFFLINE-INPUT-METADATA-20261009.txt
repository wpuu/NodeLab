具体行为
1. 实际文件入口只有在完整解析返回后，把已选择并成功处理的格式交给保存模块。
2. 记录是固定三元组：uri_lines/source_text/0；base64/decoded_text/1；not_recorded/parser_text/null。只接受精确字符串白名单，三个字段不能由调用方分别拼接。
3. 单独保存已有统计或直接生成中文报告时，默认来源未记录。匿名统计无法证明原始文件格式；记录表示调用方声明的处理选择，不是内容自动鉴定、网络测量或节点质量证明。
4. 库存 JSON 仍为v1，台账、配置组和重复关系保持原样。COMPLETE.json明确升级v2并增加三字段；中文报告显示同一映射。命令行JSON仍是纯v1统计，Markdown则显示实际选择。
5. 元信息、报告与完成标记都在首次路径操作前验证和检查可序列化性。两份报告写完后才写临时完成标记、flush/fsync并原子改名；处理失败不发布新的完成标记。
6. 旧v1完成标记不能补认为逐行文本；单独复制库存JSON也没有输入格式记录，须同时保留中文报告/完成标记。严格只接受旧v1完成标记的外部读者需要认识v2升级。
