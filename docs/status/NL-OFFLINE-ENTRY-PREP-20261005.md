## 用户使用步骤

1. 下载并完整解压验收后的 NodeLab_Offline_V1.zip。
2. 本机有 Python 3.12+ 和 Tk 时，双击 NodeLab_Offline.cmd。
3. 选择已经下载好的本地逐行节点文本，最多 512KiB。
4. 只将“复制匿名摘要”的结果用于后续讨论；原始文本留在本机。
