NodeLab 免安装Python的桌面候选（构建后使用）

此说明用于实际在Windows x64上构建并通过自检的候选包。LinuxValidation仅用于内部验证，不能在Windows运行，也不能当作Windows验收。

1. 完整解压整个Windows压缩包到本地目录。
2. 双击NodeLab_Offline.exe。必须保留同目录_internal及其他文件，不能只复制exe。
3. 该包自带Python与Tk运行文件，本机无需另装Python；不进行安装、下载或要求管理员权限。
4. 选择逐行URI或Base64文本，再点“选择文件并盘点”。原始文件最多512KiB；只盘点，不连接节点。
5. 成功后显示匿名统计，可复制摘要；报告保存在%LOCALAPPDATA%\NodeLab\Reports。
6. “打开报告并核对”只读取保存报告的三份文件，不重读原始节点文本。旧v1报告格式显示未记录。
7. 本轮用户试用仅使用随候选材料提供的虚构文本。虚构示例不是可用节点。

程序的网络/DNS与外部进程调用有拒绝保护；不带代理引擎，不修改输入文件和已有代理客户端。
“解析成功”不是节点可用或质量证明，报告核对不认证作者或历史输入。
较大报告JSON读取占用较多内存。只选已下载本地文件，网络盘、重解析点、云占位文件会拒绝。
MANIFEST.json列出代码来源、构建版本、自检范围与文件指纹，指纹不是发布签名。
本候选未做用户Windows电脑完整桌面验收，不能借用旧版本通过记录。没有真实节点验收。

licenses目录保留运行时与第三方许可文件。保留完整目录分发；不附用户节点资料。
