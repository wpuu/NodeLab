NodeLab 本机离线盘点 V1（个人自用准备版）

1. 解压整个压缩包，双击 NodeLab_Offline.cmd。
2. 需要本机已有 Python 3.12或以上，并包含Tk图形组件。缺失时只提示，不自动安装或下载。
3. 在“输入格式”中选择“逐行 URI”或“Base64 订阅文本”，再点“选择文件并盘点”。
   默认逐行 URI，不自动猜测格式。选择一份已下载的本地文本；原始文件最多512KiB。
4. 窗口显示匿名统计。“解析成功”只表示格式受支持，不代表节点可用。
5. 点“复制匿名摘要”，可以仅分享摘要。原始链接和密码留在本机。
6. JSON、中文报告保存在 %LOCALAPPDATA%\NodeLab\Reports\report-随机编号。
   一个报告目录只有存在 COMPLETE.json 才表示完整写入；失败目录不作完成结果。
   中文报告和新版完成标记记录本次选择的格式，以及行号是否来自解码后的文本。
   请一起保留报告和完成标记；单独的库存JSON仍为v1，不记录原始包装格式。
7. 再次查看保存结果时，点“打开报告并核对”，选择完整报告目录。
   此操作只读 COMPLETE.json、inventory.json、inventory.md，不读取原始节点文件，不生成新报告。
   核对三份文件的结构与一致性；缺失、不一致、格式错误、过大或不安全的本地文件会拒绝。
   单份统计JSON上限256MiB、中文报告128MiB、完成标记4KiB。JSON核对需读入内存，大报告占用较多内存。
   窗口显示根据已验证统计重新生成的匿名摘要，可以复制；格式选择不会改写已保存的格式记录。
   旧v1完成标记的输入格式只能显示“未记录”，不能从统计补认逐行文本或Base64。
   核对通过只表示文件符合一致性规则，不能证明作者身份或原始输入；没有签名或原始输入认证。
8. 关闭窗口即可。输入与已保存报告均不修改，已有代理客户端不改动。

当前解析：Trojan/VLESS 的TLS TCP、WebSocket、gRPC。
Reality、HTTPUpgrade及其他不支持项会单独统计；不会判成失效节点。
Base64 只展开一次，解码后的全部文本行继续接受原有严格校验，坏行和不支持项保留。
支持标准或URL-safe字母表（不可混用），正确填充或完全省略填充，开头UTF-8 BOM及ASCII空格/制表/换行。
空Base64、错误字符、错误填充或非规范尾位会整份拒绝，不生成完成报告。
Base64包装文件也计入512KiB，解码正文容量因此小于512KiB；行数和行号指解码后文本。
订阅网址、YAML不是支持输入，不会自动抓取；Base64展开也不新增协议支持。
完成标记升级为v2。旧v1标记及没有来源记录的单独统计只能视为格式未记录，不能补认逐行文本。

程序有运行期网络/DNS与外部进程审计拒绝；不启动代理引擎。
输入拒绝UNC、设备路径、网络盘、符号链接、Windows重解析点和云占位文件。
这不等于控制电脑上其他软件的同步、监控或恶意行为；请使用本地已下载文件。
报告仍含文件结构统计，由你决定是否分享。不要上传原始节点文本。
本包不含Python运行时，不是无依赖exe。未证明你历史E盘程序的安全性。

仅复用既有严格解析器和匿名盘点模块；idna依赖随包附许可证和版本清单。
仓库：wpuu/NodeLab。生产探测保持关闭。
